# CLI conversion

The original Shopify web-app scaffold was replaced with a local TypeScript CLI. Its temporary backup was deleted at the user's request on October 3, 2026. The existing repository `.git` directory remains in place.

The active project uses a Node/TypeScript CLI and offline diagnostics. React Router, App Bridge, Prisma session storage, webhooks, Docker deployment, Shopify app commands, and their runtime dependencies are no longer part of the active setup.

No Shopify registration, remote repository, or store data was changed by the local conversion or scaffold deletion.
